# Читаем вместе

Небольшое React-приложение для чтения постов и просмотра авторов с JSONPlaceholder.

## Запуск

```sh
npm install
npm run dev
```

## Страницы

- `/posts` — список постов и авторов.
- `/posts/:id` — полный текст поста и ссылка на автора.
- `/users/:id` — профиль автора и его публикации.
- `/favorites` — сохранённые посты; их можно удалять по одному или очистить список.

Запросы выполняются через TanStack Query с пятиминутным временем актуальности кэша. Избранное хранится в React Context на основе `useState` и сбрасывается при перезагрузке страницы. Навигация реализована на History API без дополнительной библиотеки маршрутизации.
